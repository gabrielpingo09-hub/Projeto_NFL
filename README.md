Guia do Projeto NFL 2026
Este repositório contém a página web interativa e o guia completo da temporada 2026 da NFL (National Football League). O projeto foi desenvolvido para entusiastas e novos fãs do futebol americano, reunindo calendário de partidas, classificação, simulador interativo de posições e o histórico dos Super Bowls.

🚀 Funcionalidades Principais
Calendário da Temporada Regular (2026): Listagem completa de todas as semanas (da Semana 1 até a Semana 18), incluindo datas, horários, estádios (com partidas internacionais em Londres, Madri, Munique e Cidade do México) e links diretos para os melhores momentos no YouTube.

Tabela de Classificação: Acompanhamento atualizado das conferências AFC e NFC, com abas de filtro interativas.

Guia Rápido de Regras: Seção explicativa dividida em quatro pilares para iniciantes:

O Jogo (Estrutura, quartos e duração)

Downs (As 4 tentativas e o avanço de 10 jardas)

Pontuação (Touchdowns, Field Goals, Safetys, etc.)

Faltas Principais (False Start, Holding, Pass Interference e mais)

Campo Interativo e Simulador de Jogadas (#nfl-posicoes):

Visualização esquemática dos 22 jogadores em campo.

Modo Ataque e Defesa: Descrição detalhada de cada posição (QB, RB, WR, LB, CB, etc.), suas funções e duelos-chave.

Modo Simulador: Animação de jogadas táticas (Passe, Corrida e Blitz) com rastreamento de trajetórias (trails) em tempo real.

História dos Super Bowls: Cards informativos cobrindo a trajetória das edições históricas da grande final da NFL.

🛠️ Tecnologias Utilizadas
HTML5 Semântico: Estruturação acessível com uso de tags modernas (header, section, article, aside, details).

CSS3 Avançado: Layouts responsivos, flexbox, grid e animações personalizadas.

JavaScript (Vanilla): Manipulação dinâmica do DOM para o campo interativo, controle de abas, painéis de exploração e atualização de status da classificação.

💻 Como Executar o Projeto
Como se trata de uma aplicação web puramente estática:

Clone ou baixe este repositório para o seu computador.

Abra a pasta do projeto.

Dê um duplo clique no arquivo index.html ou abra-o diretamente em qualquer navegador web moderno (Google Chrome, Firefox, Safari ou Microsoft Edge).
